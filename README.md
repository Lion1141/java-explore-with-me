Платформа для публикации событий и сбора статистики посещений.

Стек:
Java 17
Spring Boot
Spring Data JPA
Hibernate
PostgreSQL
Docker
Maven
JUnit
Mockito

Архитектура:
- main-service
- stats-service
- PostgreSQL

Функциональность:
- создание событий
- модерация
- поиск
- статистика просмотров
- подборки событий

Запуск:
docker compose up
